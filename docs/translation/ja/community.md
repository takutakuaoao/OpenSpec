# コミュニティショーケース

OpenSpec で、あるいは OpenSpec のために作られたプロジェクトやリソースを集めた、コミュニティ主導の awesome リストです。ツール、連携、ワークフロー、学習リソースを歓迎します。コミュニティのメンバーがプルリクエストを通じてこのショーケースを育て、メンテナンスしています。

掲載されているプロジェクトは、それぞれ独立してメンテナンスされています。掲載は、OpenSpec による公式のサポートや推奨を意味するものではありません。セットアップやサポートについては、各プロジェクトのドキュメントと issue トラッカーを参照してください。

<a id="projects-and-resources"></a>
## プロジェクトとリソース

- **[OpenSpec Workbench](https://github.com/VeryComplexAndLongName/OpenSpec-UI)**: OpenSpec の変更に対するエージェントの実行と監督。
- **[MySpec](https://myspec.dev)**: ガイド付きの仕様インタビューを行い、4ファイルのバンドルまたは OpenSpec 互換の変更をエクスポートするクラウドベータ版（アカウントが必要）。このサービスは、送信されたコンテンツをサードパーティの AI プロバイダーに送信するため、機密データ向けには設計されていません。
- **[openspec-guard](https://github.com/guillaume-flambard/spec-guard)**: テストを実行せずに、どの OpenSpec シナリオが Vitest または Jest のテストでカバーされているかを報告する CLI および GitHub Action。

<a id="add-your-project"></a>
## プロジェクトを追加する

このファイルに、プロジェクト名、直接リンク、そして OpenSpec との関係を示す短い説明を1行追加するプルリクエストを作成してください。

- エントリーは、OpenSpec で作られたもの、または OpenSpec の利用を支援するものに絞り、一般的な製品の宣伝は避けてください。
- 利用者が何を使えるのかを記述してください。宣伝的な主張、紹介リンク、トラッキングリンクは避けてください。
- 有料機能や必須アカウントがある場合は、エントリーに明記してください。

既存のエントリーの修正や更新も歓迎します。
